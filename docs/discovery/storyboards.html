Who was alone with Ambrose Quill?

Answer in the next slide · casegrid

The answer

  1. Ambrose is fixed at row 1, column 1, in the study. Clue 1
  2. The clock fills its own cell, so the open cells beside it are row 1, column 2 and row 2, column 3. Only the second is in row 2, so that is where Winnie stood. Clues 2, 3
  3. Hugo stands beside Winnie. The cell above her is the clock, so he is at row 2, column 2. Clue 4
  4. Iris is not in the hall, so she is in the study. The only free study cell is row 2, column 1. Clue 5

Iris Moss was the only other person in the study, so she was alone with Ambrose.

Who was alone with Cordelia Brisk?

Answer in the next slide · casegrid

The answer

  1. Cordelia is fixed at row 1, column 3, on the deck. Clue 1
  2. Teddy is in column 1 and row 2: row 2, column 1, in the cabin. Clues 2, 3
  3. The bench touches row 1, column 2, row 2, column 1, and row 2, column 3. Teddy already fills row 2, column 1, and of the other two only row 1, column 2 is in row 1, so Ines is in the cabin. Clues 4, 5
  4. The lifebuoy touches only Cordelia’s cell and row 2, column 4. Rafe stands there, on the deck. Clue 6

Rafe Dunmore was the only other person on the deck. His cell touches Cordelia’s only at a corner, so he was never beside her, but he was alone with her.

  3. Otis was in column 3.
  4. Caspar was in row 1.

Who was alone with Hesper Grayle?

Answer in the next slide · casegrid

The answer

  1. Hesper is fixed at row 2, column 3, in the stairwell. Clue 1
  2. The lens touches row 1, column 1, row 1, column 3, and row 2, column 2. Only row 1, column 3 is in column 3, so Otis is in the lamp room. Clues 2, 3
  3. Caspar is in row 1. Otis and the lens fill the rest of that row, leaving row 1, column 1. Clue 4
  4. Bryony is in a different room from Otis, so she is in the stairwell. She is not beside the lens, which rules out row 2, column 2 and leaves row 2, column 1. Clues 5, 6

Bryony Fenn was the only visitor in the stairwell with Hesper.

# CaseGrid Required Visual Assets

This document inventories all visual assets needed for the CaseGrid MVP. As instructed, placeholder visual components (SVG icons, initials, and styled tokens) are used in code, allowing final artwork to be plugged in seamlessly.

---

## 1. Brand & Global Assets

| Asset Name | Target Format | Intended Dimensions | Description |
|---|---|---|---|
| `logo-casegrid.svg` | SVG | 256x256 / vector | CaseGrid official mark. An editorial mystery symbol featuring a magnifying glass interwoven with an isometric floor grid. |
| `favicon.svg` | SVG | 32x32 / vector | Simplified grid-and-clue icon suitable for browser tabs. |
| `badge-case-closed.svg` | SVG | 160x160 | Vintage rubber-stamp or wax-seal style "CASE CLOSED" insignia for victory screen. |

- `avatar-evelyn.svg` (Suspect): Evelyn Rosewood — Ambitious younger sister in an elegant dark green dress with a pearl necklace.
- `avatar-arthur.svg` (Suspect): Arthur Vance — Cautious family solicitor in wireframe spectacles with a leather dossier under his arm.
- `avatar-clara.svg` (Suspect): Clara Mercer — Inquisitive rare literature collector with auburn hair in an updo and a magnifying loupe.
- `avatar-julian.svg` (Suspect): Dr. Julian Sterling — Serious physician in a tweed vest holding a black medical satchel.
- `avatar-beatrice.svg` (Suspect): Beatrice Finch — Observant head housekeeper in crisp linen with a chatelaine key ring.

# CaseGrid web application

The browser client for CaseGrid, built with React, TypeScript, Vite, and Tailwind CSS.

Run commands from the repository root:

```bash
pnpm install
pnpm dev
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

Product requirements live in [`../../docs/PRD.md`](../../docs/PRD.md).
